## Perfil profesional

Ingeniero de Sistemas con sólida base en soporte de aplicaciones empresariales, administración de sistemas operativos Linux y Windows, infraestructura tecnológica distribuida y gestión de bases de datos. Complemento mi perfil con desarrollo backend moderno en JavaScript.

| Área | Enfoque |
| :--- | :--- |
| **Soporte e infraestructura** | Diagnóstico y solución de incidentes, configuración y mantenimiento de equipos, plataformas y servicios tecnológicos en entornos empresariales distribuidos. |
| **Linux y automatización** | Administración de Ubuntu Linux, usuarios y permisos, scripts Bash, tareas programadas con Cron y acceso remoto por SSH. |
| **Gestión de datos** | Consulta y soporte sobre PostgreSQL, Oracle y MySQL en sistemas de información críticos. |
| **Desarrollo backend** | JavaScript, Node.js, Express, Prisma ORM y APIs REST. |
